Contributing
============

The `contributor guide
<https://github.com/itpplasma/SIMPLE/blob/main/CONTRIBUTING.md>`_ describes
building, testing, reporting bugs and submitting pull requests.

The `coding standard
<https://github.com/itpplasma/SIMPLE/blob/main/docs/development/coding-standard.md>`_
covers Fortran, Python and build files. The `review policy
<https://github.com/itpplasma/SIMPLE/blob/main/docs/review-policy.md>`_ defines
risk tiers, evidence requirements and golden-record rules.
